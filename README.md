# 鹿紫云一表情包资源包

这是一个用于 AstrBot 表情包管理器的鹿紫云一图片资源包，图片位于 `memes/kashimo/`。

## 来源与版权

图片由仓库所有者从 Bilibili 页面整理后提供：

- https://www.bilibili.com/opus/1191770136648876037

请确认你拥有这些图片的使用或转载权限。仓库保留原始文件名，未声称拥有图片本身的版权。

## AstrBot 使用

可以将 `memes/kashimo/` 目录下载到本地，再通过表情包管理器导入；也可以在插件页面中逐张上传。建议按以下语义分类：

- challenge：挑衅、发起对决
- strong-opponent：遇到强者、有意思
- rule-added：规则追加、宣布信息
- disdain：无语、嫌弃、嘲讽
- victory：胜利、认可、战斗结束

`manifest.json` 中记录了资源包 ID、来源和目录信息。
