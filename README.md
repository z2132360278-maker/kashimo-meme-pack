# 鹿紫云一表情包资源包

这是一个用于 AstrBot 表情包管理器的鹿紫云一资源包索引与来源记录。

## 版权说明

仓库暂不直接重新分发漫画截图或网友二创图片，仅记录公开来源链接。使用前请确认素材作者授权、站点条款和所在地区的版权规则。

## 适合分类

- challenge：挑衅、发起对决
- strong-opponent：遇到强者、有意思
- rule-added：规则追加、宣布信息
- disdain：无语、嫌弃、嘲讽
- victory：胜利、认可、战斗结束

## AstrBot

图片经授权后，按 `memes/<分类>/` 放置，并在 AstrBot 表情包管理器中导入或上传；不要把来源页面的热链地址直接当作长期图床。
